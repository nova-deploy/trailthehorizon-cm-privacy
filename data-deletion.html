Confidentialité Suppression des données

Demander la suppression de mes données

Version préparée le 5 octobre 2026.

Les demandes sont prises en charge manuellement par le gestionnaire de TrailTheHorizon CM.

Pour une demande concernant les données détenues par TrailTheHorizon CM, écrivez à :

contact@trailthehorizon.com
Objet conseillé : Suppression de mes données — TrailTheHorizon CM.

Informations utiles

  • Votre nom d’utilisateur Instagram.
  • Le lien de la publication ou l’identifiant du commentaire concerné, si vous le connaissez.
  • Le périmètre de la demande : un commentaire précis ou l’ensemble des données vous concernant.

N’envoyez aucun mot de passe, App Secret ou token d’accès. Le gestionnaire pourra demander une information complémentaire proportionnée pour identifier les données et s’assurer que la demande vous concerne.

Traitement de la demande

Le gestionnaire recherche les données correspondantes, examine les éventuelles obligations de conservation et réalise les suppressions nécessaires dans les données de l’application. Le traitement est manuel à ce stade. Vous recevez une réponse sur les suites données à votre demande et, le cas échéant, sur les motifs d’une limite.

Nous répondons dans un délai d’un mois après réception. En cas de complexité ou de demandes nombreuses, ce délai peut être prolongé de deux mois supplémentaires ; les motifs vous sont communiqués dans le premier mois. Vous pouvez contester la réponse auprès de la CNIL ou de l’autorité compétente.

La suppression des copies détenues par TrailTheHorizon CM ne supprime pas automatiquement le commentaire d’origine sur Instagram ni les données conservées par Meta. Vous pouvez gérer votre commentaire directement dans Instagram.

Le retrait d’une autorisation Meta et la suppression des données déjà enregistrées sont deux opérations distinctes. Pour demander l’effacement des copies détenues par l’application, utilisez le contact ci-dessus.
